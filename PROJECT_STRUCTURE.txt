╔══════════════════════════════════════════════════════════════════════════╗
║                            DATA FLOW                                      ║
╚══════════════════════════════════════════════════════════════════════════╝

1. User Opens Site
   ↓
2. page.tsx loads with AppProvider
   ↓
3. Sample properties loaded from data/properties.ts
   ↓
4. Navigation renders with default filters
   ↓
5. Map renders with all property markers
   ↓
6. User interacts:
   │
   ├─→ Clicks Marker
   │   ↓
   │   PropertyPreviewCard appears
   │   ↓
   │   User clicks "View Details"
   │   ↓
   │   PropertyDetails panel slides in
   │
   ├─→ Uses Filters
   │   ↓
   │   Filter state updates in Context
   │   ↓
   │   Properties filtered in page.tsx
   │   ↓
   │   Map re-renders with filtered markers
   │
   ├─→ Clicks "Add Property"
   │   ↓
   │   AddPropertyModal opens
   │   ↓
   │   User completes 3 steps
   │   ↓
   │   Property submitted (console.log in demo)
   │
   └─→ Toggles Dark Mode
       ↓
       Dark mode state updates
       ↓
       HTML class added/removed
       ↓
       All components re-style via Tailwind
